# 📖 드라마바이블 이어듣기

Android Firefox에서 성경을 듣다가 멈추고, 다음 날 **이어 듣기**를 누르면 그 위치부터 다시 재생합니다. 영상별 진도와 날짜별 청취 기록은 내 기기에만 저장합니다.

공동체성경읽기의 [사도행전 전체 통독](https://m.youtube.com/watch?v=jVO5lOOS37w)을 기본 제공하며 다른 유튜브 성경 영상도 링크로 추가할 수 있습니다. 채널의 공식 프로그램은 아닙니다.

## 휴대폰에서 처음 설치하기

1. **Android Firefox**에서 [Violentmonkey 설치 페이지](https://addons.mozilla.org/ko/android/addon/violentmonkey/)를 열고 확장을 설치합니다.
2. 같은 Firefox에서 **[드라마바이블 스크립트 설치](https://raw.githubusercontent.com/JonathanBlackDoctor/drama-bible-resume/main/drama-bible-resume.user.js)**를 누릅니다. Violentmonkey의 설치 화면에서 이름과 유튜브 접근 범위를 확인하고 설치합니다.
3. **처음에는 현재 듣던 위치가 포함된 유튜브 링크**를 Firefox에서 엽니다. 링크의 `t=` 시작 시간을 최초 진도로 사용합니다. 위치가 없는 링크라면 **기록·영상 → 현재 위치 직접 수정**에서 시작할 분:초를 입력합니다.
4. 유튜브 오른쪽 아래의 **이어 듣기**를 누릅니다. 이미 듣는 중이면 같은 버튼이 **일시정지**로 바뀝니다.

스크립트 코드가 글자로만 표시되면 Violentmonkey가 설치·활성화됐는지 확인합니다. 필요하면 Firefox 메뉴의 **확장 프로그램 → Violentmonkey**에서 URL로 설치하는 기능에 위 설치 링크를 붙여 넣으세요. 일반 다운로드 파일을 실행하는 프로그램은 아닙니다.

> 영상 링크가 유튜브 앱으로 넘어가면 Firefox의 ‘앱에서 링크 열기’ 설정을 끄거나 링크를 Firefox 주소창에 붙여 넣으세요. 비공개 탐색 탭 대신 일반 탭을 사용하세요.

## 매일 사용하기

- 사도행전 유튜브 페이지를 Firefox의 **바로가기**에 추가해 두고, 등교할 때 열어 **이어 듣기**를 누릅니다.
- 화면을 잠그고 듣는 기능은 기존에 쓰는 백그라운드 재생 확장이 담당합니다. 이 스크립트는 재생 위치와 기록을 관리합니다.
- 일시정지하거나 이어폰으로 멈추면 마지막 위치를 저장합니다. 화면이 활성화되어 있으면 재생 중에도 약 3초마다 변경분을 저장합니다.
- 다른 페이지에서는 **📖 성경 듣기**를 눌러 패널을 엽니다. 영상을 선택한 뒤 **이어 듣기**를 누르면 해당 유튜브 페이지로 이동합니다. 페이지 이동 뒤 브라우저가 자동 재생을 막으면 재생 버튼을 한 번 더 눌러야 할 수 있습니다.
- **기록·영상**에서 새 성경 영상의 링크와 이름을 추가할 수 있습니다. 같은 영상을 다시 추가해도 기존 진도는 유지합니다.
- 완주하면 완료를 표시합니다. 다음 영상은 목록에서 직접 선택합니다. 처음부터 다시 들으려면 **현재 위치 직접 수정**에서 `0:00`을 저장합니다.

## 기록과 백업

- 마지막 위치는 영상마다 따로 저장합니다. 뒤로 돌려 들으면 되돌아간 위치부터 이어 듣습니다.
- 날짜별 기록은 **Asia/Seoul** 기준으로 영상명, 첫·마지막 청취 위치, 청취 시간을 보여줍니다. 같은 구간을 다시 들은 시간도 청취 시간에 포함하며, 건너뛴 시간과 광고 시간은 제외합니다.
- **백업 저장**으로 JSON 파일을 내려받습니다. **백업 가져오기**는 기록을 합치며 같은 기록을 중복 추가하지 않습니다. 새로 저장된 기기 진도를 오래된 백업으로 되돌리지 않습니다.
- 백업은 5MB 이하, 영상 1,000개·청취 세션 20,000개 이하를 지원합니다. 형식이 틀린 백업은 기록을 쓰기 전에 거절합니다. 가져오기 도중 저장소 오류가 나면 일부 항목만 합쳐질 수 있으며 같은 파일로 다시 가져올 수 있습니다.
- 기록은 **Violentmonkey의 이 스크립트 전용 저장소**에 있습니다. 자체 서버·로그인·분석 도구·자동 기기 동기화는 없습니다. Violentmonkey/스크립트 제거 또는 Firefox 앱 데이터 삭제 전에 백업하세요. 개인정보가 담긴 백업을 공개 GitHub 저장소에 올리지 마세요.

## 알아두기

- Android의 절전·백그라운드 제한으로 저장 이벤트가 늦어지면 마지막 몇 초가 남지 않을 수 있습니다. 앱 강제 종료 직전 기록 저장은 보장하지 않습니다. Firefox의 배터리·백그라운드 데이터 제한을 확인하세요.
- YouTube의 광고 표시와 플레이어가 제공하는 영상 ID·길이가 본영상과 일치할 때만 저장합니다. 영상 확인이 안 되면 **기록 대기**를 표시합니다. 광고 표시 방식이나 유튜브 화면 구조가 바뀌면 수정이 필요할 수 있습니다. 실시간 방송과 Shorts는 지원하지 않습니다.
- 청취 시간은 관찰된 재생 구간 기준입니다. 30초 넘게 관찰하지 못한 구간은 과대 집계를 막기 위해 청취 시간에서 제외할 수 있습니다. 재생 위치는 다시 확인한 실제 위치로 저장합니다.
- 여러 탭에서는 마지막으로 재생을 시작한 탭이 기록합니다. 이전 탭의 늦은 저장이 새 탭의 진도를 덮어쓰지 않습니다. 진도 충돌을 피하려면 같은 영상은 한 탭에서 사용하세요.
- 기본 시작 위치는 최초 등록 때 한 번만 적용됩니다. 나중에 다른 `t=` 링크를 열어도 기존 진도가 우선합니다. 바꾸려면 위치 수정 기능을 사용하세요.
- **Android 실기기의 화면 잠금·이어폰·Firefox 재시작 조합은 개발 환경에서 검증하지 못했습니다.** 아래 항목으로 실제 기기에서 확인해 주세요. 이 프로젝트는 백그라운드 재생 자체를 보장하지 않습니다.

## 개발과 검증

Node.js 22.12 이상과 pnpm을 사용합니다. 사용자 설치에는 개발 도구가 필요 없습니다.

```sh
pnpm install --frozen-lockfile
pnpm run check
pnpm test
node scripts/preview.cjs
```

미리보기 주소는 터미널에 표시됩니다. `tests/browser-fixture.html`은 모의 플레이어를 쓰는 **개발용 화면**이며 실제 유튜브를 재생하지 않습니다. 실제 청취 기록과 분리된 로컬 저장소를 사용합니다.

자동 검증은 URL 제한, 초기 위치, 재접속, 되감기·탐색, 배속, 광고·버퍼링, 서울 자정, 영상별 분리, 탭 충돌, 백업 검증·중복 병합, 터치 재생 실패 안내와 DOM 화면 동작을 포함합니다.

### Android 실기기 확인

1. 이어 듣기를 누르고 약 15초 듣습니다. 이어폰으로 멈췄을 때 표시 위치와 저장 위치가 맞는지 확인합니다.
2. 화면을 잠근 채 1분 듣고, 잠금 화면에서 멈춘 뒤 기록이 늘었는지 확인합니다.
3. Firefox를 정상 종료했다 다시 열고 이어 듣기로 같은 위치부터 시작하는지 확인합니다.
4. 뒤로 이동해 잠깐 듣고 멈춘 뒤, 다음 실행에서 되감은 위치가 유지되는지 확인합니다.
5. 광고가 나올 경우 본영상의 진도가 광고 시간으로 바뀌지 않는지 확인합니다.
6. 백업을 저장하고 다시 가져온 뒤 진도 유지와 기록 중복 여부를 확인합니다.

## 유지보수

스크립트는 외부 코드를 불러오거나 빌드할 필요가 없는 단일 파일입니다. 업데이트는 파일 상단의 버전을 높여 게시하면 Violentmonkey의 업데이트 기능으로 받을 수 있습니다. 자동 업데이트를 끈 경우 설치 링크를 다시 열어 갱신할 수 있습니다.

소스는 MIT 라이선스이며 유튜브 영상·음원 권리는 각 권리자에게 있습니다.
